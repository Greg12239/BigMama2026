# SEO Controlled Skill

## When to use
Only when user asks for SEO.

## Allowed SEO work
- title/meta description,
- canonical,
- Open Graph,
- semantic headings,
- local section,
- FAQ,
- image alt text,
- sitemap,
- robots,
- Restaurant JSON-LD.

## Forbidden
- fake reviews,
- fake ratings,
- fake phone/address/hours,
- keyword stuffing,
- broad content rewrites without approval.
