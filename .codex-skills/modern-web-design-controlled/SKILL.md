# Modern Web Design Controlled Skill

## When to use
Only when user explicitly asks for design improvement.

## Big Mama design language
- orange neon,
- white/orange premium contrast,
- bold rounded typography,
- appetite-focused imagery,
- street-food confidence,
- mobile-first ordering.

## Restriction
Do not redesign entire sections unless explicitly asked.

## Controlled improvement rule
A design improvement must be:
- local,
- reversible,
- commercially useful,
- consistent with existing approved layout.

## Business filters
Every visual decision must support:
- ordering,
- trust,
- appetite,
- memorability,
- local dominance.
