# Big Mama Codex Skills

These are controlled local skill adapters for Codex.

They are intentionally strict.

They are not permission to freely edit the website.

Priority order:
1. `strict-change-control`
2. `safe-restore`
3. task-specific skill only if user explicitly asks:
   - `modern-web-design-controlled`
   - `motion-controlled`
   - `mobile-conversion-controlled`
   - `seo-controlled`

The approval gate in `AGENTS.md` always wins.
