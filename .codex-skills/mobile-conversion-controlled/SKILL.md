# Mobile Conversion Controlled Skill

## When to use
Only when user asks for mobile conversion improvements.

## Allowed improvements
- sticky mobile order/call/map actions,
- efood CTA refinement,
- mobile tap target improvements,
- simple visibility logic.

## Restrictions
- Do not move desktop navigation without approval.
- Do not change menu/category layout without approval.
- Do not invent phone/map data.
- Do not add fake business data.

## Business goal
Reduce taps from hungry mobile user to:
- order,
- call,
- maps.
